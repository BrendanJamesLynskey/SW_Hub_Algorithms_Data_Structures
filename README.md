# Algorithms & Data Structures — Series Hub

Twenty-four interactive decks on the core of computer science, from complexity and arrays to network flow, plus an LLM-examined coding gym to practise them by hand.

**Live index:** https://brendanjameslynskey.github.io/SW_Hub_Algorithms_Data_Structures/

**Who this is for.** Anyone preparing for coding interviews or revisiting the fundamentals.

**How to use it.** Start with complexity, learn the structures, then the algorithms that use them; the coding gym at the end is for practice by hand.
